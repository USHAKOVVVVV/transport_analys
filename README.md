# Очистка и унификация данных по ДТП (2020–2024)

## Обзор проекта
Данный этап включает в себя сборку единого каркаса данных из 5 ежегодных выгрузок. Результатом являются три реляционные таблицы, готовые к загрузке в PostgreSQL или ClickHouse.

## Структура данных
На выходе сформированы три основные сущности:

1. **fact_dtp**: Основная таблица происшествий.
   - Ключ: `dtp_id`.
   - Содержит: Время, географию (координаты, адреса), погодные условия и общие последствия (кол-во раненых/погибших).
2. **fact_participant**: Данные об участниках.
   - Ключ: `participant_id`.
   - Связь: `dtp_id` (N:1 к fact_dtp), `vl_id` (N:1 к fact_vehicle).
   - Содержит: Роль участника, возраст, нарушения ПДД, степень тяжести последствий.
3. **fact_vehicle**: Данные о транспортных средствах.
   - Ключ: `vehicle_id`.
   - Связь: `dtp_id` (N:1 к fact_dtp).
   - Содержит: Марку/модель, год выпуска, тип собственности, VIN и описание повреждений.

## Качество данных и аномалии
По результатам первичного аудита выявлены следующие особенности:

### 1. Полнота (Missing Values)
* **География**: Поля `road_name` и `road_loc` имеют ~35 000 пропусков. Это критично для пространственного анализа. Вероятно, данные отсутствуют для происшествий внутри жилых зон или на неразмеченных участках.
* **Технические поля**: Поле `scheme_code` отсутствует в 24 500+ записях.
* **Адреса**: В 8 записях полностью отсутствуют `district_name` и `place_full_path`.

### 2. Целостность (Integrity)
* **Referential Integrity**: 100%. В системе отсутствуют "висячие" записи (участники или ТС без родительской записи ДТП).
* **Дубликаты**: Полные дубликаты строк отсутствуют.

### 3. Логические проверки
* Диапазон дат соответствует ТЗ (2020–2024).
* Возрастные аномалии (младше 0 или старше 110 лет) не зафиксированы / отфильтрованы.

## Инструкция по загрузке
Данные подготовлены в формате `.csv` (разделитель — запятая, кодировка UTF-8). 
Колонки унифицированы:
- Имена приведены к `snake_case`.
- Кириллица в названиях полей полностью устранена.
- Типы данных подготовлены для автоматического распознавания (Numeric, DateTime, String).

## Подробное описание полей (Data Dictionary)

### 1. Таблица fact_dtp (События ДТП)
Центральная таблица, содержащая пространственно-временные характеристики и общие показатели последствий:
dtp_id	Уникальный идентификатор происшествия (Primary Key)
moment_date / moment_time	Дата и время совершения ДТП
type_code / type_name	Код и текстовое описание вида ДТП (напр., столкновение, наезд)
vehicles_count	Общее количество транспортных средств-участников
dead_count / injured_count	Общее кол-во погибших / раненых (всего)
dead_children_count / injured_children_count	Кол-во погибших / раненых детей
place_latitude / place_longitude	Географические координаты (WGS84)
place_full_path	Полный иерархический путь к месту (Регион; Округ; Район)
district_name / district_id	Наименование и ID административного округа/района
road_name / street_name	Название дороги или улицы
road_loc / house_num	Километровая отметка или номер дома
traffic_lane_amount	Общее количество полос движения на участке
meteo_clouds	Состояние облачности и осадков
light_type_code	Освещенность (светло, сумерки, освещение включено/выключено)
source_year	Технический маркер года из исходного файла выгрузки


### 2. Таблица fact_participant (Участники)
Детальная информация о людях, вовлеченных в происшествие:
participant_id	Уникальный идентификатор записи участника
dtp_id	Ссылка на событие ДТП (Foreign Key)
vl_id	Ссылка на транспортное средство (если участник был в ТС)
person_age	Возраст участника (полных лет)
person_birthday	Дата рождения
part_type_code	Категория участника (водитель, пешеход, пассажир)
hv_type_code	Степень тяжести последствий для здоровья
driver_service_length	Стаж вождения (для водителей)
main_pdd_derangements	Основные нарушения ПДД, зафиксированные за участником
person_escape_code	Отметка об оставлении места происшествия


### 3. Таблица fact_vehicle (Транспортные средства)
Технические характеристики и повреждения автомобилей.:
vehicle_id	Уникальный идентификатор ТС (Primary Key)
dtp_id	Ссылка на событие ДТП (Foreign Key)
mark_name / model_name	Марка и модель транспортного средства
manufacture_year	Год выпуска ТС по документам
vin / reg_number	VIN-номер и государственный регистрационный знак
transport_type_name	Категория/тип ТС (легковой, грузовой, такси и т.д.)
owner_org_name	Наименование организации-собственника (если применимо)
damage_description	Текстовое описание повреждений кузова и узлов
tyre_type_code	Тип установленных шин (летние, зимние шипованные и т.д.)

**Словарь маппинга полей доступен в файле `data_dictionary.xlsx`.**
